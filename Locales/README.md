# Translations

The addon is in English for now. To translate it, copy `phrases.txt` to `<locale>.lua` (say `deDE.lua`), set that
code at the top, translate the right-hand side of each line and delete the lines you leave in English. Then list
the file in `ShortestPathForever.toc` straight after `Locales\enUS.lua` and open a pull request. If that's a
hassle, paste your translations into an issue and I'll add them.

The codes are deDE, esES, esMX, frFR, itIT, koKR, ptBR, ruRU, zhCN and zhTW. A phrase you leave out stays in English.
